## 短版简介

看山谜案馆是一座多智能体推理剧场。玩家通过问话、出示证据和角色对质查明真相，刘看山陪伴调查、回答是非问题并提供分阶段提示。作品还提供生成剧场，将文字、文本文件或网址改编成新案子，并支持出题给朋友。

## 完整简介

两万元学费转进了同学名下的银行卡，对方却说自己一分钱也没见过。看山谜案馆从这起校园谜案出发，让玩家担任调查员，与四位各怀秘密的 AI 角色交谈，在口供、聊天记录和收款证据之间寻找矛盾，逐层拆穿谎话。

每个角色拥有独立的知情范围、信任度和对话历史。世界引擎保存事实与线索，判定证据是否足以拆穿谎话，并在条件满足时触发角色对质。核查智能体检查回复中的越界与矛盾，不通过时要求重写。刘看山作为调查搭档，以“是、不是、不重要”回答玩家的有限次提问，并在卡住时提供分阶段提示。玩家提交推理后进入对应结局，看到评级、汤底和反诈知识点。

生成剧场接收文字、文本文件和网址，由编剧智能体改编成新案子，经过程序检查与可解性检查后开局。玩家也能选择出题给朋友，在出题人页面查看调查进度。

## 技术方案

Python + FastAPI 提供游戏和生成接口，原生 HTML/CSS/JavaScript 构建网页界面。剧本使用 YAML 描述事实、角色、秘密、谎话、线索、事件与结局。引擎计算条件、信任度、回合数和评级，演员模型负责角色表达，核查模型检查回复，编剧模型负责素材改编与剧本生成。模型通过 OpenAI 兼容接口调用，可分别配置演员和编剧；模拟模式支持无密钥开发。剧本检查器执行格式、引用、线索可达性和结局检查，并进行两次模型盲答检查。

## 创意与价值

- **证据改变对话**：玩家出示线索后，角色从坚持谎话到承认事实，调查行为直接推动剧情。
- **AI 陪伴进入玩法**：刘看山与玩家共同调查，提示随线索进度变化；有限次是非问答鼓励玩家组织判断。
- **从玩案到出题**：招牌案件提供打磨过的体验，生成剧场让玩家用自己的素材创作，再邀请朋友调查。

招牌案件围绕校园刷单与收卡骗局展开，玩家通过重建资金、推广和人际关系链，理解小额返利、垫资连单与出售银行卡带来的具体后果。
