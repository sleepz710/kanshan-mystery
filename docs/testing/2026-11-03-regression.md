## 问题与修复

| 问题 | 复现方式与影响 | 修复及回归 |
|---|---|---|
| 无素材确认启动生成 | 新对话直接发送「直接开始」「开始生成」「没看过答案」「看过答案」「全新」，按钮文字被当成素材，甚至覆盖模型的澄清决定 | 无已有素材、无附件时本地要求补充题材，不调用模型、不创建任务、不记录伪素材；同时验证有题材或有效附件可正常继续 |
| 修订诊断丢失 | 第一轮盲答发现 q3 缺线索；第二轮生成返回损坏 JSON 或缺少 `story`；第三轮只剩格式错误，失去第一轮的具体问题 | 没有新稿时保留旧稿和已有诊断，追加本次格式问题；覆盖两个失败分支 |
| 盲答假通过 | 汤面回复 `answers:{}`，或包含多余题号、选项外的值，过去会按零题正确处理，可能放过「只看汤面就能答出」的检查 | 题号须完整且无多余项，每题只能返回对应选项原文或 JSON `null`；非法回复抛出 `ReplyFormatError`，保留生成服务的未完成检查提示；完整 `null` 仍是合法的无法推断 |
| 发布与取消不一致 | 工作线程已开始写盘时取消任务，线程继续保存，而任务报失败、无 `story_id`；分享模式还可能无法交付原始出题人令牌 | 进入发布后等待同一次写盘完成，再统一更新令牌、`story_id` 和 done；发布前取消仍按中止处理；play/share 两种阻塞写盘场景均验证 |
| 质量提示丢失 | 生成页显示未全部通过，回首页或从分享链接新开一局却看不到，刷新后也丢失 | 目录和开局接口可选返回 `checked`；仅明确布尔值透传，未知省略。首页独立提示行和对局状态持续显示 `false`，旧任务错误兼容显示；明确 `true` 覆盖旧警告，未知不虚构通过 |
