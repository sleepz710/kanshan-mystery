## 已实现

- 模型设置在桌面模式挂载，提供保存、掩码读取、一次最小连接请求。保存写入用户数据目录并立即更新模型环境变量。OpenAI 必须明确提供两组模型名。原生「应用」菜单可以再次进入设置、返回首页和退出。
- `KANSHAN_DATA_DIR` 控制模型配置、生成剧本、草稿、所有权文件、WebView2 profile、日志、浏览器记录与桌面后端对局。默认使用 `%APPDATA%/KanshanMystery`。普通网页版保留原配置与运行入口。
- 页面 `<head>` 中先恢复 `kanshan:*` localStorage，再执行页面已有脚本；保存操作同步提交本机服务。跨随机端口迁移依靠用户数据目录中的记录文件。桌面同时保存并恢复后端 GameState。

执行 `desktop/build.ps1`，使用独立构建环境 `kanshan-desktop-20261104`。第一次在工作区更新 EXE 图标资源遇到 Windows `EndUpdateResourceW` 访问限制，脚本改用系统 TEMP 作为构建中间目录后成功。成品是包含 Python DLL、后端、前端、官方剧本及 WebView2/.NET 桥接依赖的 onedir 文件夹。
