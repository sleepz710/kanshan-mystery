# 人工修订演示案

这三份 YAML 来自已有精修稿的人工修订，原稿与修订稿指纹见 `manifest.json`。三案均通过结构、好玩度、真实双盲答及真实角色完整路线，修订稿按本次结果记录 `checked:true`，三份原始生成稿保留 `checked:false`。

1. 在资源管理器地址栏打开 `%APPDATA%\KanshanMystery`，创建或进入 `stories` 文件夹。
2. 将 `revised` 下的三个 `demo-*-revised.yaml` 复制进去，同名文件选择跳过。
3. 打开桌面版，在案件目录选择《汐潮馆的第七位住客》《潮汐第七人》或《末班车的干伞》开局。

网页版将三份文件复制到项目 `data/stories/`。自定义 `KANSHAN_DATA_DIR` 的桌面版使用该目录的 `stories/`。

逐题证据、修订说明、真实问话和验收数据见上一级的 `2026-11-04-task19-demo-acceptance.md`、本目录的三个 `*-playthrough.json` 与 `summary.json`。调查路线经过预先编排，最后答题模型仅收到公开记录。
