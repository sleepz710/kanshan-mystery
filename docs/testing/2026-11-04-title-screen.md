## 走查

1. 标题 → 回车「开始探案」→ 子菜单 → 回车「从已有剧场游玩」：地址变成 `#cases`，馆藏案件 1 个、我的剧场 1 个。
2. 方向键选中招牌案件 → 回车开局 → 档案弹窗标题下不再出现「null」→ 问一回合 → 回首页：主菜单出现「继续调查 一笔消失的学费 · 第 1 回合」，案件行显示「4 位角色 · 调查到第 1 回合」。
3. 在 `#cases` 按 Esc 回到标题的子菜单并选中「从已有剧场游玩」；下移到「新建剧场」回车进入 `#new`；浏览器后退回到子菜单并选中「新建剧场」。
4. 新建剧场：点「贴一碗海龟汤」填入素材 → 「交给编剧」→ 跳到 `/studio/?chat=<id>`，对话里有开场白、素材和编剧的回复，编剧页没有玩法切换；点「直接开始」生成完成，案件卡片只有「开始调查」。
5. 回到 `#cases`：新生成的案件排在「我的剧场」第一个（按 `created_at`），带「检查未全部通过」。在浏览器存储里加一段生成中（精修）和一段失败的对话：生成中一行显示进度、「精修中」和每秒走动的用时，失败一行显示「生成没有完成 · 回到对话」，两行都链接到对应编剧对话。
6. 1280×720、1600×900、1920×1080 布局一致；1280×1024、2560×1080 下画面铺满不留黑边，标题、菜单和声音开关不重叠，无横向滚动。
7. 桌面模式：主菜单出现「模型设置 DeepSeek · key 未填写」（黄色）；注入 `window.pywebview.api.quit` 并发 `pywebviewready` 后出现「退出」，键盘选中回车调用了 `quit()`。没填 key 时「交给编剧」提示「请先打开模型设置，填写自己的 API key。」，素材留在输入框。
8. 鼠标移到菜单项上选中项跟着走，焦点同步。
9. 控制台：网页版只有 `/assets/audio/bgm.mp3` 的 404（曲子还没放）；桌面模式另有一条未填 key 时接口按预期返回的 503。

`pytest`：608 项通过。
