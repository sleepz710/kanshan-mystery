## 样本审阅

对已产出的三案进行了文本与程序审阅。三案均仍需修订，目前没有可直接用于最终视频的合格候选。修订优先顺序为《潮汐失声》《308病房的呼叫铃》《雪夜账本疑云》。

- 《潮汐失声》证据题支撑较清楚，但开局未锁定的事实可能提前回答结局题，事故与演出时间存在冲突。
- 《308病房的呼叫铃》有可演示的机制，但开局泄底、证据歧义及真相结局可重试状态需修正。
- 《雪夜账本疑云》物品转移、题目前提与时间线不一致，拆谎证据仍在说谎者本人手中。

审阅基于文本、结构和好玩度程序检查。真实角色互动与计时另见任务18和20记录，当前没有将文本审阅计入玩家通关统计。

根据这些实际缺陷补充了设计与填表提示，要求物品转移及题目前提共用时间线、核心隐情进入受条件限制的秘密或谎话，以及真相结局禁止重试。提示补强后的真实生成尚受402阻断，效果需恢复额度后验证。

## 重现命令

```powershell
python -m eval.pregen --live --env-file .env --count 6 --concurrency 2 --stories-dir "$env:TEMP\kanshan-pregen\stories" --output-dir data/eval/pregen
```

`.env` 中的演员、编剧模型名将被实际采用，报告中的 models 字段保存该次值。每例报告保留耗时、结构与好玩度问题、全部管线问题和安全失败类型。

DeepSeek错误码依据 [官方文档](https://api-docs.deepseek.com/quick_start/error_codes/)。
